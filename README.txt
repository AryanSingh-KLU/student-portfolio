STUDENT PORTFOLIO WEBSITE

Files:
- index.html: website structure and content
- style.css: styling, Flexbox, Grid, and responsive media queries
- script.js: mobile navigation, copyright year, and contact form feedback

HOW TO OPEN:
1. Extract the ZIP file.
2. Open VS Code.
3. Choose File > Open Folder and select the student-portfolio folder.
4. Open index.html.
5. Right-click index.html and choose Open with Live Server.
   If Live Server is not installed, install the Live Server extension or open index.html directly in your browser.

CUSTOMIZE:
Replace "Your Name" and "Your School Name" in index.html with your details.
The contact form only displays validation feedback; it does not send emails.
